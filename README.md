# نقاشی و حدس

بازی چندنفرهٔ نقاشی و حدس (شبیه skribbl.io) روی Cloudflare Workers.

## معماری

| بخش | نقش |
|---|---|
| **Worker** (`src/index.js`) | مسیریابی: `/ws/:code` → اتاق، `/api/quickplay` → بازی سریع، بقیه → فایل‌های استاتیک |
| **Durable Object `GameRoom`** (`src/room.js`) | یک اتاق = یک DO. WebSocket (با Hibernation)، وضعیت بازی، امتیاز، تایمر با Alarm، پخش خطوط نقاشی |
| **Durable Object `Matchmaker`** (`src/matchmaker.js`) | فهرست اتاق‌های عمومی برای «بازی سریع» (SQLite) |
| **Static Assets** (`public/`) | رابط کاربری فارسی RTL با فونت Vazirmatn |

وضعیت بازی در storage ذخیره می‌شود، پس اگر DO بین پیام‌ها hibernate شود چیزی گم نمی‌شود.

## اجرا و انتشار

```bash
npm install
npm run dev          # اجرای محلی: http://127.0.0.1:8787
npm run test:e2e     # تست سرتاسری (در حال اجرا بودن dev لازم است)

npx wrangler login
npm run deploy       # انتشار روی حساب Cloudflare شما
```

Durable Objects با SQLite روی پلن رایگان Workers هم در دسترس است.

## قوانین بازی

- ۲ تا ۸ بازیکن؛ میزبان تعداد دور (۱ تا ۱۰) و زمان نقاشی (۳۰ تا ۱۸۰ ثانیه) را تعیین می‌کند.
- در هر دور همه یک‌بار نقاش می‌شوند. نقاش از بین ۳ کلمه یکی را انتخاب می‌کند (۱۵ ثانیه).
- راهنمای کلمه به‌تدریج حرف‌به‌حرف باز می‌شود.
- امتیاز حدس درست بر اساس زمان باقی‌مانده و ترتیب حدس؛ نقاش هم به‌ازای هر حدس درست امتیاز می‌گیرد.
- اگر همه حدس بزنند نوبت زودتر تمام می‌شود. حدس‌های درست برای دیگران پخش نمی‌شوند.
- نقاش و حدس‌زننده‌ها در حین نوبت فقط با هم چت می‌کنند.
